# 📊 Dashboard de TI – Brasil 2025

Este projeto apresenta um dashboard interativo desenvolvido com **HTML, CSS e JavaScript**, utilizando **Chart.js** para visualização de dados.  
O objetivo é demonstrar insights sobre o mercado de tecnologia no Brasil em 2025.

## 🚀 Tecnologias utilizadas
- **HTML5**
- **CSS3**
- **JavaScript**
- **Chart.js**
- **VS Code**

## 📂 Estrutura do projeto
├── index.html
├── style.css
├── script.js
